# Reference scripts

Unmodified course helper scripts, from
[BredaUniversityADSAI/Yr3ElectivesStudyMaterial/SystemDesign](https://github.com/BredaUniversityADSAI/Yr3ElectivesStudyMaterial/tree/main/SystemDesign).

- `getNO2Readings.py` — `get_latest_no2()` for Luchtmeetnet station NL10240
- `getTrafficReadings.py` — `download_and_decompress`, `build_index_map`, `extract_measurements` for the four NDW A27 sites

`ingest_air.py` and `ingest_traffic.py` build on these.
